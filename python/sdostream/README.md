# SDOstream – Tests (Streaming Outlier Detection)

Von **Projektroot** aus:

- **Alle Tests:**  
  `python python/sdostream/test_sdostream.py`
- **Nur bestimmte Tests (z.B. 1, 2, 4):**  
  `python python/sdostream/test_sdostream.py --test 1 2 4`

Voraussetzung: `maturin develop` im Projektroot. Optional: `scikit-learn`.
